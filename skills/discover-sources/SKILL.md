# Discover sources

Read ../../guides/policy.md and the upstream skill's source-strategy and ex-ussr-locale-guide references. The shared research engine is ../../vendor/ex-ussr-kinship-research/SKILL.md.

Use ../../regional-archives/README.md and ../../resources/README.md before selecting routes. `python3 scripts/search_catalogue.py --place <place> --year <year> --record-type <type>` searches local descriptions; it does not determine historical custody automatically.

Resolve place variants and dated jurisdictions, then check parish/religious jurisdiction separately. Use ../../regional-archives/historical/finding-a-volost.md when modern geography does not identify the keeper. Consult upstream seed-sources.md for additional routes. Read the region's coverage gaps, not only its institution names.

For each useful route, distinguish a directory listing, catalogue description, tested search, viewed image, and blocked access. Save exact evidence only in the private case. Finish with source-backed custodian candidates, what can actually be accessed, and the next discriminating search. Never equate a local catalogue keyword hit with a custody decision.
