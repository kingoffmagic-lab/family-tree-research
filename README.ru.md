# Family Tree Research

Самодостаточный навык для ИИ-агентов на основе [ex-ussr-kinship-research](vendor/ex-ussr-kinship-research/SKILL.md).

[English](README.md) · [Архивы](regional-archives/README.md) · [Другие источники](resources/README.md) · [Пробелы](regional-archives/COVERAGE.md)

Храните семейное дело вне этой папки. Для основных команд нужен Python 3.9+.

Задание агенту:

> Прочитай SKILL.md. Создай частное дело, уточни имеющиеся материалы и выбери один полезный вопрос. Используй каталоги источников и исходный навык. Сохраняй источники и неопределённости.

Команды — в [README](README.md). По умолчанию результаты содержат только людей, явно отмеченных умершими; `--private-output` предназначен для частного использования. Перед передачей проверьте содержание и ссылки. Программы ничего не публикуют.

[Правила](guides/policy.md) · [Порядок работы](guides/workflows.md)

Каталог охватывает 15 бывших союзных республик, Польшу и Финляндию. Охват частичный; наличие архива не означает доступность сканов. Для исторических мест используйте [датированный поиск хранителя](regional-archives/historical/finding-a-volost.md).

[Установка для Claude, Codex и других агентов](guides/compatibility.md): копируйте всю папку, а не один файл.

Уточните, какие документы и прежние исследования сохранились, кто сообщил рассказ и насколько точны даты. Снимайте страницы целиком с полями и оборотом; оригиналы не изменяйте. Неизвестное оставляйте неизвестным.

Учебное дело: `python3 scripts/demo.py --case-dir ../demo-case`. Все люди и документы в нём вымышлены.
