# Case workflow

Use the upstream evidence method and [project policy](policy.md). One agent is sufficient.

## Start or resume

Ask about existing materials once. Create a case outside the skill, or resume its registers, research-state.md and plan/BOARD.md. Preserve originals; log searches and save source provenance, access dates, archive references, checksums and uncertain readings.

## Coordinate and integrate

If collaborators are authorized, only the integrator updates canonical registers. Researchers write work/<task-id>/handoff.md with task-prefixed provisional IDs. Compare the handoff's base version with current registers; review identity and relationship proposals separately and allocate IDs against the current data. A second transcription is not an independent source.

## Continue or finish

Audit after integration, retain honest warnings, update the board and resume position, and name the next useful check. Do not repeat searches without a new reason. Finish when the question is answered at its evidence level or useful reachable routes and blockers are recorded.
